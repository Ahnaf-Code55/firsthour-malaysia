# Demo script (about 75 seconds)

Record on a phone-sized window, English first, then a few seconds in Bangla. Captions in English. Use only the fictional sample case.
Run: `VITE_FIXTURE=1 npm run dev` (or live mode if `scripts/live-check.mjs` shows 10/10).

| Time | Show | Say |
|---|---|---|
| 0:00 | Black screen, then the fake police-call chat from the sample case | "It's 2:36 pm. A caller says he's a police inspector. Four minutes ago, this student sent RM 1,200." |
| 0:10 | Start page, press **Try the sample case** | "Almost every scam tool tries to stop the scam before the money moves. FirstHour starts after the loss." |
| 0:18 | Plan page: facts with the quoted lines | "FirstHour reads the messages and pins every fact to the exact line it came from. Amount, who was paid, the account number." |
| 0:28 | Edit the amount, show the script change | "If it got something wrong, fix it. The script updates." |
| 0:36 | Step 1: bank picker, tap **Call CIMB**, then the NSRC 997 step | "Then what to do first. Every number comes from an official page, with the date we checked it. The AI never writes a phone number." |
| 0:48 | Tap the tick, show the timeline entry | "Tick a step and it goes on your timeline." |
| 0:54 | Check a message: paste the recovery-fee message, red warning | "Later, someone offers to recover the money for a fee. FirstHour says why that's a second scam." |
| 1:03 | Toggle to Bangla, then the printable summary | "In English or Bangla, and a summary to take to the police and the bank. Nothing is saved." |
| 1:12 | Title card: "FirstHour. The first safe hour after a scam." | "FirstHour Malaysia. The first safe hour after a scam." |

Notes
- Say once, clearly: other tools detect scams; FirstHour starts after the loss.
- If fixture mode is used, say "this sample runs from a saved reading" in the description, not in the voice-over.
- Do not promise recovery of money anywhere.
